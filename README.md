# خطة تدريس حقائب النشاط الصفّي — مدارس ابن خلدون (معارف) ١٤٤٨هـ

منصّة تشغيلية للمدرسة، **محتواها مُعمّى** ولا يُفتح إلا بكلمة الدخول التي تصرفها
إدارة المدرسة.

## ما في هذا المستودع

| الملف | الوصف |
|---|---|
| `index.html` | بوّابة الدخول — لا محتوى فيها |
| `app.enc` | المنصّة كاملةً مُعمّاة |
| `حقائب/*.enc` | صفحات الحقائب مُعمّاة |
| `sw.js` | عامل خدمة يفكّ تعمية صفحات الحقائب في متصفّح المستخدم |

## المنظومة

- المفتاح = `PBKDF2-HMAC-SHA256(كلمة الدخول, ملح, 310000 دورة)` → ٢٥٦ بت
- كل ملف = `IV(12) ‖ AES-256-GCM(المحتوى)` بمتّجه تهيئة مستقلّ

**كلمة الدخول لا تُرسَل ولا تُخزَّن**: يُشتقّ منها المفتاح في متصفّح المستخدم،
ويبقى في الذاكرة وحدها. وليس على الخادم بايتٌ واحد سافر.

> ⚠️ هذا يحمي المحتوى ممّن لا يعرف الكلمة. ومن عرفها فله المحتوى كاملاً —
> فالكلمة تُصرف لمنسوبي المدرسة، وتُبدَّل بإعادة بناء النسخة عند الحاجة.
